# Introducción de la Aplicación
¿No puedes dormir por la noche? ¿Quieres recuperar el sueño durante un viaje? ¿Te falta concentración?
Necesitas esta aplicación de "Ruido Blanco":
 * Bloquea distracciones y mejora la concentración
 * Alivia el estrés y calma las emociones
 * Alivia los dolores de cabeza y enmascara el tinnitus
 * Relajación mental y sueño reparador
 * Colección de lluvia, truenos, viento y bosque con efectos de sonido nivel HIFI
 * Interfaz limpia y estética, estilo Material Design
 * Software de código abierto, sin anuncios

Este proyecto adopta el patrón de diseño MVP, logrando una arquitectura clara y utilizando los frameworks más populares de la actualidad. Con un diseño global basado en Material Design, ¡es sin duda un proyecto de código abierto que merece la pena revisar!
